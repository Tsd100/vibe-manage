# 扫描进度与任务栏图标清晰度设计

## 目标

保持现有项目管理数据语义不变，让扫描过程可见，并改善 Windows 高 DPI 任务栏中的图标清晰度。

## 扫描

仓库发现完成后，扫描器逐个仓库回调 `(已完成数, 总数, 仓库名)`；UI 主线程显示进度，结束或失败时恢复现有结果提示。每个仓库只遍历一次源文件，同时计算最早和最近修改时间，不引入可能漏掉变更的缓存。保留原有 Git、用途和时间来源规则。

## 图标

保留蓝色工作台主题。16–48 像素帧采用笔画更粗、元素更少的小尺寸图形；较大帧保留现有细节。Windows 原生图标按窗口 DPI 选择匹配的 ICO 帧，写入实际顶层窗口句柄，避免始终加载 256 像素后由任务栏缩小。

## 验证

先写失败测试，覆盖扫描进度、单次文件遍历、图标尺寸与 Windows 句柄选择；随后运行完整测试。重启正式应用，核对扫描记录和任务栏显示。只修改本项目代码与图标资产，不触碰被扫描仓库。

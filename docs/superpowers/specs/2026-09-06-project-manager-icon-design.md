# 项目管理看板图标设计说明

## 已确认方向

采用预览中的 B 方案“蓝色工作台”。图标以当前应用的蓝色主色为基础，表达一个简洁的项目工作台：蓝色圆角底、浅色面板、三条项目列表线和底部三枚状态节点。图标不放文字，保证在 Windows 标题栏、任务栏和系统托盘缩小后仍然清晰。

## 使用范围

- 窗口标题栏使用同一枚图标，替换 Tk 默认羽毛图标；
- Windows 任务栏使用同一枚 `.ico` 类图标，并通过稳定的 AppUserModelID 避免显示 Python 默认图标；
- 系统托盘使用同一枚图标，保持窗口和托盘识别一致；
- 生成 Windows `.ico`，包含 16、20、24、32、48、64、128、256 像素尺寸，供后续安装器复用；
- 运行时数据和业务仓库不受影响，图标资产保留在项目工作区内。

## 实现边界

- 使用 Pillow 绘制确定性的矢量风格图形，避免运行时依赖网络或远程图片；
- 窗口通过 `iconphoto` 设置 Pillow 生成的 RGBA 图像，并持有引用防止 Tk 回收；
- 窗口同时通过 `iconbitmap(default=...)` 设置 Windows 任务栏使用的 `.ico` 文件；主入口在创建 Tk 窗口前设置 `VibeManage.ProjectManager` AppUserModelID；
- Windows 窗口句柄再通过 `WM_SETICON` 写入 256px/16px 图标，覆盖直接用 `python.exe` 启动时的任务栏默认图标回退；
- 托盘继续使用相同的 Pillow 图像；
- 图标生成逻辑单独放在 `src/project_manager/icon.py`，UI 只调用公共函数；
- 增加纯函数测试，验证图标尺寸、RGBA 模式和关键颜色；增加 Tk smoke test，验证窗口不再使用默认图标路径。
- 增加 Windows 原生图标辅助函数的非 Windows 安全测试。

## 验收标准

1. 应用窗口标题栏和 Windows 任务栏不再显示 Tk/Python 默认图标；
2. 托盘图标与窗口图标保持 B 方案视觉一致；
3. 生成的 `.ico` 可被 Pillow 读取，包含多尺寸帧；
4. 完整测试通过，应用以隐藏控制台方式重启后正常响应；
5. 不修改 `D:\Github` 下任何被扫描项目。
